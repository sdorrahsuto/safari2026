遊獵英語

Safari 途中最實用的英文詞彙庫 · 地形 · 植物 · 動物行為

🌍 地形名稱 Landscape & Terrain
Savanna
熱帶稀樹草原
東非最典型的景觀，稀疏喬木與廣闊草原並存
Bushveld
灌木草原
低矮灌木叢密集分佈的草原地帶，能見度較低
Kopje / Kopies
花崗岩孤岩丘
草原上散落的花崗岩巨礫群，豹與獅子常棲息其上
Escarpment
崖壁 / 斷層懸崖
大裂谷邊緣的陡峭岩壁，如東非大裂谷沿線景觀
Rift Valley
大裂谷
東非大裂谷（Great Rift Valley），奈瓦夏湖、納庫魯湖所在
Crater
火山口
如恩戈羅恩戈羅火山口（Ngorongoro Crater），形成天然圍欄
Floodplain
氾濫平原
雨季河流溢出後形成的廣闊濕地，是動物的水源地
Marsh / Swamp
沼澤 / 濕地
常年積水的低窪地帶，水鳥與河馬的主要棲地
Watercourse / Riverbed
河道 / 乾河床
乾季時河床裸露，仍是動物挖掘地下水的重要地點
Waterhole / Pan
水坑 / 天然水池
乾季中動物最重要的聚集地，晨昏是最佳觀察時機
Lugga
季節性溪谷
半乾旱地區雨季才有水的短暫溪流河谷
Salt Lick
鹽舔地
富含礦物質的土壤地塊，動物定期前來舔食補充礦物質
Gorge
峽谷
如奧杜威峽谷（Olduvai Gorge），人類起源重要考古遺址
Open Plains
開闊草原
視野無遮蔽的廣闊平坦草地，大遷徙主要發生地帶
Riparian Zone
河岸林地帶
河流兩岸的植被帶，生物多樣性最豐富的微型棲地
Acacia Woodland
金合歡林地
金合歡樹密集分佈的林地，長頸鹿與花豹最愛的棲息環境
🌿 植物名稱 Flora & Vegetation
Acacia Vachellia / Senegalia spp.
金合歡
東非草原最具代表性的樹種，傘狀樹冠，長頸鹿的主食，也是花豹儲藏獵物的樹
Baobab Adansonia digitata
猴麵包樹
樹幹粗壯可達 10 公尺，壽命逾千年，又稱「生命之樹」，塔蘭吉雷 NP 以此著稱
Whistling Thorn Vachellia drepanolobium
哨刺金合歡
球形空心蟻巢附著在刺上，風吹過會發出低鳴聲，故名「哨刺」
Fever Tree Vachellia xanthophloea
黃皮刺槐（發燒樹）
樹皮呈黃綠色，早期殖民者誤以為是瘧疾的來源，故稱「發燒樹」，奈瓦夏湖畔常見
Leleshwa Tarchonanthus camphoratus
樟樹灌木
馬賽馬拉常見的銀灰色葉片灌木，葉片揉碎有樟腦香氣，黑犀牛偏好取食
Red Oat Grass Themeda triandra
紅燕麥草
塞倫蓋提與馬賽馬拉最主要的草種，乾季轉為金紅色，構成草原最經典的色調
Euphorbia
大戟屬仙人掌樹
多肉植物，外型似高大仙人掌，樹液有毒，常作天然圍籬，東非多地可見
Fig Tree Ficus spp.
無花果樹
河岸林帶常見的大型喬木，果實是靈長類、鳥類與蝙蝠的重要食物來源
Sausage Tree Kigelia africana
香腸樹
果實形似巨大香腸，可重達 10 公斤，河馬和大象偶爾取食，不可人類生食
Commiphora / Myrrh Bush
沒藥灌木
半乾旱地帶常見灌木，樹脂即為傳統香料沒藥（Myrrh）的來源
Papyrus Cyperus papyrus
紙莎草
濕地與河岸常見的高大莎草，是古埃及紙張的原料，也是鷺鷥和翠鳥的棲息植被
Doum Palm Hyphaene thebaica
杈葉椰子
北肯亞半乾旱地帶特有的分叉椰子樹，象群和長頸鹿喜食其果實
🐾 動物行為 Animal Behaviour
Game Drive
遊獵車觀察
乘坐越野車在保護區內尋找和觀察野生動物的核心 Safari 活動
Sighting
目擊 / 觀察到
成功發現動物，如：「We had a great leopard sighting this morning.」
Stalk / Stalking
潛行接近
掠食者在狩獵前低伏緩慢靠近獵物的行為，是拍攝的最佳時機之一
Ambush
伏擊
掠食者預先埋伏在獵物必經路線上，等待時機發動攻擊
Mock Charge
假衝鋒
動物（尤其是象或水牛）張耳朝前衝但中途停下的威嚇行為，非真正攻擊
Full Charge
真實衝鋒
耳貼、頭低、目光直視的真正攻擊衝鋒，立即告知導遊
Kill / Fresh Kill
獵殺 / 新鮮獵物
掠食者剛獵殺的獵物，現場往往吸引鬣狗、禿鷹等二次取食者聚集
Carcass
屍骸
動物的遺骸，是食腐動物（禿鷹、鬣狗）的重要食物來源
Scavenge / Scavenger
食腐 / 食腐動物
以其他動物死亡遺骸為食的生態角色，禿鷹和鬣狗是典型代表
Predator / Prey
掠食者 / 獵物
生態鏈核心概念，掠食者包括獅、豹、獵豹；獵物如羚羊、斑馬
Territory / Territorial
領地 / 具領地性
動物以氣味、糞便或叫聲標記並防禦的活動範圍
Musth
公象狂暴期
成年公象每年進入的高睪酮素激動期，顳腺分泌黑液，行為極具攻擊性
Rutting / Rut Season
發情季 / 交配季
雄性動物為爭奪交配權而激烈競爭的季節，常伴隨打鬥與叫聲
Grooming
互相理毛
靈長類（狒狒）或其他社會性動物互相清理毛髮，強化社會連結
Mud Wallow / Wallowing
泥浴
犀牛、水牛、象等動物在泥坑翻滾以降溫並防蟲的行為
Dust Bath
沙浴
鳥類或部分哺乳動物在乾燥沙土中翻滾清潔皮膚的行為
Alarm Call
警戒叫聲
動物察覺危險時發出的特定警報聲，其他物種可藉此判斷掠食者位置
Flehmen Response
翻唇嗅味反應
雄性動物翻起上唇以費洛蒙感測器官辨別雌性發情狀態的特殊表情
Symbiosis / Mutualism
共生 / 互利共生
兩種不同物種互相受益的關係，如水牛與牛椋鳥、犀牛與紅嘴牛椋鳥
Migration / The Great Migration
遷徙 / 大遷徙
每年百萬頭角馬與斑馬在塞倫蓋提與馬賽馬拉之間的循環移動，世界最壯觀自然奇景
River Crossing
河流橫渡
大遷徙中角馬冒險橫渡馬拉河的高峰時刻，尼羅鱷在此埋伏獵食
Matriarch
母系家長
象群中帶領家族的最年長母象，其決策對族群生存至關重要
Bachelor Herd
雄性聯盟群
被踢出家群的成年雄性動物組成的鬆散群體，常見於公象或年輕雄獅
Pride (Lions)
獅群
獅子的社會群體單位，通常由多頭雌獅、1～4 頭雄獅及幼獅組成
Coalition
（雄獅）流浪聯盟
2～5 頭成年雄獅合作占領獅群、共享交配權的聯盟關係
Amboseli Dust Devil
塵旋風
安博塞利常見的小型龍捲風柱，由乾熱地表的對流氣流形成，無危險
Canopy / Understorey
樹冠層 / 林下層
森林垂直結構分層，長頸鹿取食樹冠，猴子活躍於中間層
Dispersal
離群擴散
年輕動物離開出生族群獨自建立新領地的行為，是基因多樣性的重要機制
